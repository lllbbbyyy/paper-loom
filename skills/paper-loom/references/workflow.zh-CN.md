# 工作流程与文档约定

## 1. 确定修改范围

记录稿件版本、目标读者、论文类型、语言、篇幅要求、现有证据和本轮工作范围。优先使用已给出的信息和合理默认，不因可选偏好反复等待。保留现有稿件格式和位置。本 skill 增加配套 `narrative/` 目录，不要求将原稿改成 Markdown，也不自动创建投稿流程。

完整论文模式需要清点全部正文，包括摘要、已有的讨论或局限章节及结论。对包含实质性主张的图注也进行标注。公式、算法、表格和参考文献条目作为关联材料，不机械拆成句子；标题归入章节记录，解释公式的文字仍要维护句子记录。

局部请求只清点指定范围，阅读足够的上下文来核对入口和出口关系。保留未涉及章节，将尚未检查的联系标为“未审阅”。

## 2. 润色前建立全文论证图

全文提纲记录：

- 目标读者、当前问题、重要性与有证据支持的核心主张。
- 理解研究缺口前需要知道的背景。
- 可追溯关系表：需求／问题 → 挑战 → 洞察 → 设计响应 → 评价问题 → 证据 → 主张。
- 章节顺序及各章贡献。
- 篇幅优先级和未解决依赖。

给概念分配稳定 ID，例如 `CH-01`、`IN-01`、`DS-01`、`EX-01`、`CL-01`。证据链接到真实文件或来源，明确区分“已有观测”“计划”“缺失”和“不适用”。计划实验不能被引用为结果。证据与主张冲突时，收窄主张、解释权衡或提出具体调查，不能暗中更换比较对象或指标。

理论、定性或其他非实验研究，可以用相应的证明、分析或来源论证承担证据环节。不要为了套用实证论文结构而虚构实验或模块。

对应关系需要理由，不能只对应名字。写清设计**如何**应对挑战，以及**什么观测**能够支持这种解释。多个挑战可以共用一个机制，一个实验也可以支持多个主张。背景介绍不必强行挂接实验。

## 3. 独立记录与稳定身份

```text
narrative/outline.md
narrative/sections/SEC-ABSTRACT.md
narrative/sections/SEC-INTRO.md
narrative/paragraphs/P-INTRO-01.md
narrative/sentences/S-INTRO-001.md
```

移动单元后保留 ID，阅读顺序由显式有序清单决定，不依赖文件名排序。章节按序列出段落 ID，段落按序列出句子 ID。各子单元链接到父单元和正文位置。保留原句或原文片段，避免仅依靠容易变化的行号判断同步状态。

| 层级 | 必需内容 |
|---|---|
| 全文 | 问题、读者、核心主张、论证与证据对应、章节顺序、篇幅安排、待补缺口 |
| 章节 | 目的、主要内容、读者已有知识、读后获得的认识或问题、相邻章节关系、逐段提纲、支撑的主张 |
| 段落 | 目的、主要观点、在章节中的作用、前后关系、逐句提纲、证据依赖 |
| 句子 | 当前原句、主要强调点、表述内容、前后关系、已知与新增信息、证据状态、正文位置与修订状态 |

结构上没有前项或后项时可标为 `START` 或 `END`，说明读者进入时的背景或最后获得的认识，不虚构邻居。摘要是独立阅读路径，末句不必过渡到引言；参考文献是证据去向，不是结论叙事的下一步。

## 4. 写出有信息量的衔接标注

对进入关系说明：

1. 前一单元已经建立了哪个具体概念或结论？
2. 还留下什么问题、区分或缺失前提？
3. 当前单元如何推进它？

对离开关系说明下一单元要接收的概念或问题。不能只写“提供背景”，必须说明为哪项判断提供什么背景。逻辑关系必须有依据：先后发生不等于因果，分数提高不等于所提机制得到证明。

审阅已有稿件时，区分实际关系与预期关系。例如：“预期：接口问题引出方法。实际：上一句只列了组件，没有说明为什么接口信息需要保留。”先修复正文，再把关系标为已完成。

## 5. 从出问题的最高层级修复

- 研究问题不清：先修改全文论证，再润色过渡。
- 章节出现时读者还不具备前提：调整位置或补充前提。
- 段落反复切换任务：拆分或重组。
- 句子引入未解释概念：在需要处定义或说明动机。
- 连接词暗示了无依据的因果：修正关系，或加入有依据的前提。

采用足以解决实际问题的最小修改。衔接已经清楚时，不在每段末尾重复总结，也不为每个边界增添专门过渡句。

## 6. 同步维护

改变含义的修改按以下顺序传播：

1. 同步修改正文与对应句子记录。
2. 更新受影响的相邻句记录和段落逐句提纲。
3. 段落任务变化时，更新章节提纲。
4. 主张或证据变化时，按需更新全文论证图、摘要和结论。

拆分时保留一个原 ID，为新增单元分配新 ID。合并时保留一个 ID，删除失效链接，在简短修订说明中记录退役 ID。不能把已被否决的句子当作当前原句继续保留。只有项目需要版本历史时才保留历史副本。

翻译可能改变句数。保留论证关系，通过明确的跨语言映射允许一对多，不强迫两种语言使用相同句法。

## 7. 交付与结束

交付干净正文及维护后的记录。报告缺失前提、实验与主张脱节等实质性修复，不以标点修改数量衡量成果。区分写作完成与研究证据缺失。缺少证据时，用准确收窄的主张或明确标记的工作占位完成授权范围内的写作，并列出所需证据，不为了满足故事结构而启动实验或编造发现。
